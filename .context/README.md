# Repository context

The `.context` directory gives maintainers and automation a concise, versioned understanding of this repository.

It may contain:

- the current public objective and phase;
- accepted decisions and links to repository ADRs;
- public constraints, risks, and next actions;
- terminology needed to contribute safely.

It must never contain consumer names, private repository references, production identifiers, credentials, internal URLs, support data, or copied private planning material. Context is curated public documentation, not a session transcript or operational dump.

`current.md` is intentionally short and should be updated whenever the active phase changes.
